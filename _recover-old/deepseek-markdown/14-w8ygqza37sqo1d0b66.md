Это нелинейное интегральное уравнение можно решить, заметив, что интеграл не зависит от переменной `x`. Обозначим константу

\[
C = \int_a^b g(t) y(t) \, dt.
\]

Тогда исходное уравнение принимает вид

\[
y(x) \cdot (1 + C) = f(x).
\]

Отсюда получаем, что решение должно быть пропорционально функции \( f(x) \):

1.  Если \( 1 + C = 0 \), то из уравнения следует \( f(x) \equiv 0 \). В этом случае любая функция \( y(x) \), удовлетворяющая условию \( \int_a^b g(t) y(t) \, dt = -1 \), будет решением. Решение неединственно.
2.  Если \( 1 + C \neq 0 \), то
    \[
    y(x) = \frac{f(x)}{1 + C}.
    \]
    Чтобы найти константу \( C \), подставим это выражение в её определение:
    \[
    C = \int_a^b g(t) \cdot \frac{f(t)}{1 + C} \, dt = \frac{1}{1 + C} \int_a^b g(t) f(t) \, dt.
    \]
    Обозначим
    \[
    B = \int_a^b g(t) f(t) \, dt.
    \]
    Тогда для \( C \) получаем квадратное уравнение:
    \[
    C(1 + C) = B \quad \Rightarrow \quad C^2 + C - B = 0.
    \]
    Его корни:
    \[
    C_{1,2} = \frac{-1 \pm \sqrt{1 + 4B}}{2}.
    \]

**Итоговое решение**:

\[
\boxed{
y(x) = \frac{2f(x)}{1 \pm \sqrt{1 + 4B}}, \quad \text{где } B = \int_a^b g(t) f(t) \, dt
}
\]

**Особые случаи**:

*   **При \( f(x) \equiv 0 \)**:
    *   Если \( B = 0 \), то решение неединственно: любая функция \( y(x) \), для которой \( \int_a^b g(t) y(t) \, dt = -1 \), является решением.
    *   Уравнение \( C^2 + C = 0 \) также имеет корень \( C = 0 \), которому соответствует тривиальное решение \( y(x) \equiv 0 \).

*   **При \( B = -\frac{1}{4} \)** корень один (\( C = -\frac{1}{2} \)), и решение единственно: \( y(x) = 2f(x) \).

Таким образом, при ненулевой \( f(x) \) и \( B \neq -\frac{1}{4} \) уравнение имеет два формальных решения, соответствующих разным константам \( C \). Физический или математический контекст задачи может подсказать выбор знака (например, требование конечности решения или его поведения при \( B \to 0 \)).

Уравнение \( u_t = u_{xx} + F(u, u_x) \) допускает автомодельное решение вида \( u(x,t) = t^b \phi(x/\sqrt{t}) \) тогда и только тогда, когда функция \( F(u, w) \) удовлетворяет условию инвариантности относительно растяжения переменных. Это условие приводит к двум возможным формам \( F \):

1. **Случай \( b \neq 0 \):**  
   \[
   F(u, w) = u^{p} \, \Phi\!\left( u^{q} w \right),
   \]
   где \( p \) и \( q \) — константы, связанные соотношением \( p + 2q = -1 \), а \( \Phi \) — произвольная функция одного аргумента.

2. **Случай \( b = 0 \):**  
   \[
   F(u, w) = w^{2} \, \Psi(u),
   \]
   где \( \Psi \) — произвольная функция.

Эти два семейства исчерпывают все возможности для существования автомодельных решений в данном уравнении.
