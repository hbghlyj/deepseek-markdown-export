Частные решения уравнения

\[
y'''' - c y'' = a e^{\lambda y} + b e^{2\lambda y},
\]

отличные от константы, существуют в виде решений уравнения первого порядка

\[
(y')^2 = A e^{\lambda y} + D,
\]

где константы \(A\) и \(D\) выражаются через параметры \(a\), \(b\), \(c\), \(\lambda\) следующим образом:

\[
A = \pm 2 \sqrt{\frac{b}{3\lambda^3}}, \quad D = \frac{2a}{\lambda^3 A} + \frac{c}{\lambda^2}.
\]

При этом предполагается, что \(b/\lambda^3 \geq 0\) для вещественности \(A\), и знаменатели не обращаются в ноль.

В зависимости от знака \(D\) получаются следующие явные решения (с произвольными постоянными \(K > 0\) или \(C\)):

1. **Если \(D > 0\)**, то
   \[
   e^{\lambda y} = \frac{4K^2 D e^{2\mu x}}{(K^2 e^{2\mu x} - A)^2},
   \]
   где \(\mu = \mp \frac{\lambda \sqrt{D}}{2}\).

2. **Если \(D < 0\)**, то, полагая \(\beta = \sqrt{-D} > 0\),
   \[
   e^{\lambda y} = \frac{\beta^2}{A} \sec^2 \left( \frac{\beta \lambda}{2} x + C \right),
   \]
   при условии \(A > 0\). Если \(A < 0\), решение выражается через гиперболические функции.

3. **Если \(D = 0\)**, то решение имеет логарифмический вид
   \[
   y = -\frac{2}{\lambda} \ln \left( -\frac{\lambda}{2} \sqrt{A} (x + C) \right),
   \]
   где \(A = -\frac{2a}{c\lambda}\), и параметры связаны условием \(b c^2 = 3\lambda a^2\).

Эти решения охватывают различные частные случаи, включая ранее известные логарифмические решения.
