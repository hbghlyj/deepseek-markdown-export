Спасибо за ссылку на статью А.Д. Полянина (2019). Я знаком с этим классом работ, где систематически изучаются **функционально-разделимые решения** (functional separable solutions) нелинейных уравнений с переменными коэффициентами.

---

### **Краткое содержание подхода из указанной статьи:**
1. **Общий вид уравнений**:  
   Рассматриваются уравнения реакция-диффузии вида  
   \[
   u_t = a(x) u_{xx} + b(x) u_x + F(x, u),
   \]  
   где \(a(x)\), \(b(x)\) — заданные функции, \(F(x, u)\) — нелинейный член (может содержать произвольные функции).

2. **Анзац функционально-разделимого решения**:  
   \[
   u = U(z), \quad z = \theta(t) + \psi(x).
   \]  
   Здесь \(U\), \(\theta\), \(\psi\) — искомые функции. Этот анзац обобщает:
   - решения с разделением переменных (\(\theta(t)\) линейна, \(\psi(x)\) произвольна),
   - решения типа бегущей волны (\(\theta(t) = \lambda t\), \(\psi(x) = \mu x\)),
   - автомодельные решения (\(\theta(t) = \ln t\), \(\psi(x)\) степенная),
   - и другие комбинированные формы.

3. **Метод определения**:  
   Подстановка анзаца в уравнение приводит к условиям согласования, которые часто сводятся к **переопределённой системе ОДУ** для \(\psi(x)\), \(\theta(t)\) и алгебраическим/дифференциальным ограничениям на коэффициенты уравнения. Решение этой системы позволяет найти явный вид \(z\) и соответствующее ОДУ для \(U(z)\).

4. **Пример из нашего обсуждения**:  
   Для уравнения  
   \[
   u_t = u_{xx} + x^2 f(u)
   \]  
   анзац \(u = U(z)\), \(z = t + \frac{x^2}{2}\) является частным случаем функционально-разделимого решения с  
   \[
   \theta(t) = t, \quad \psi(x) = \frac{x^2}{2}.
   \]  
   Подстановка даёт \(U_{zz} + f(U) = 0\), что полностью согласуется с методом статьи.

5. **Сила метода**:  
   Позволяет находить точные решения для уравнений с **двумя произвольными функциями** (в коэффициентах или нелинейностях), при условии, что они удовлетворяют определённым согласующим условиям. Это расширяет множество уравнений, допускающих явные решения.

---

### **Практическая ценность для ответов:**
- В дальнейшем, при запросах на точные решения нелинейных уравнений с переменными коэффициентами, можно целенаправленно применять анзац \(u = U(\theta(t) + \psi(x))\) и выводить условия согласования.
- Метод особенно эффективен для уравнений вида  
  \[
  u_t = [g(u) u_x]_x + h(x) f(u),
  \]  
  где \(g(u)\), \(h(x)\), \(f(u)\) могут быть произвольными функциями (при некоторых ограничениях, вытекающих из условий согласования).
