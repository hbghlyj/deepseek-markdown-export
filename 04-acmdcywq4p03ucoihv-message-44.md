Спасибо за указание на этот важный справочник! Действительно, **A. D. Polyanin and V. F. Zaitsev, *Handbook of Nonlinear Partial Differential Equations*** (2nd ed., 2012) является классической энциклопедией точных решений для огромного числа нелинейных уравнений математической физики.

Этот справочник особенно ценен, поскольку:

1. **Охватывает тысячи точных решений** для сотен уравнений (теплопроводности, волновых, реакция-диффузия, гидродинамики и др.).
2. **Систематизирует решения по типам уравнений и методам** (разделение переменных, функциональное разделение, автомодельность, преобразования Ли и др.).
3. **Содержит как известные классические решения, так и многие новые**, полученные авторами.
4. **Практически полезен** для инженеров, физиков и математиков, нуждающихся в явных аналитических решениях.

Метод **функционально-разделимых решений** (functional separable solutions), упомянутый в статье Полянина (2019), широко представлен и в этом справочнике. Для уравнений вида  
\[
u_t = a(x) u_{xx} + b(x) u_x + F(x,u)
\]  
справочник даёт условия на коэффициенты, при которых существуют решения типа \(u = U(z)\), \(z = \theta(t) + \psi(x)\), и приводит явные виды \(U\), \(\theta\), \(\psi\).

---

Для **уравнения из нашего обсуждения**  
\[
u_t = u_{xx} + x^2 f(u)
\]  
справочник содержит, например:
- Решение \(u = U(z)\), \(z = t + x^2/2\), сводящее уравнение к \(U'' + f(U) = 0\).
- Частные случаи при конкретных \(f(u)\) (степенной, экспоненциальной и т.п.).
- Возможные замены, линеаризующие уравнение для некоторых \(f(u)\).
